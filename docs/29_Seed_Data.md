# 29 Seed Data

## Objective
Provide initial reference data for development and testing.

## Seed Categories

- Roles
- Users
- Suppliers
- Grade Definitions
- Moisture Ranges
- Storage Areas

## Rules

- Seed data must be idempotent.
- Production secrets must never be seeded.
- Preserve manually created records.

## Development Data

- Sample suppliers
- Sample receipts
- Sample AI results

## Security

- Use non-sensitive values.
- Separate development and production seeds.
