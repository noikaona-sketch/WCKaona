# 31 Storage Buckets

## Objective
Define storage bucket structure and access control.

## Buckets

- wood-receipts
- receipt-images
- ai-results
- reports
- audit-files

## Access

- Private by default.
- Signed URLs for temporary access.
- No public buckets.

## Validation

- File type checks.
- File size limits.
- Duplicate detection by checksum.

## Audit

- Log uploads.
- Log replacements.
- Log deletions.

## Future

- Compression
- Archive storage
- Malware scanning
- Usage dashboard
